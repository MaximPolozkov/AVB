# **http-сервис**

Обрабатывает входящие запросы. 
Сервер запускается по адресу http://127.0.0.1:8080 
(значение по умолчанию можно изменить).

# *Требования*

Для установки и запуска проекта, необходим poetry [poetry](https://python-poetry.org/docs/#installing-with-the-official-installer)

# *Установка зависимостей*

Для установки зависимостей, выполните команду:
poetry init
